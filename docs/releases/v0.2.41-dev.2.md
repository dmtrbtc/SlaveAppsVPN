# SLAVE VPN v0.2.41-dev.2

Dev-сборка с унификацией ядра Mihomo и исправлениями Android, найденными при
испытании на физическом ARM64-устройстве с Android 16.

## Основные изменения

- Mihomo обновлён до `v1.19.30` на Windows и Android.
- Загрузки Windows-ядра теперь проверяются по закреплённым SHA-256.
- Android Gradle/Capacitor-проект восстановлен для воспроизводимой CI-сборки.
- Исправлена загрузка gomobile JNI перед первым обращением к Mihomo.
- Исправлено сохранение гостевого входа после пропуска onboarding.
- Добавлено восстановление VPN после смерти процесса и холодного запуска.
- Устранена утечка дублированного TUN-дескриптора при ошибке конфигурации.
- Повторное подключение с Kill Switch использует последнюю рабочую нативную
  конфигурацию и не зависит от уже заблокированного DNS.
- Always-on VPN корректно восстанавливает туннель после полной перезагрузки.

## Проверено на устройстве

- VPN-подключение по подписке и через логин/пароль;
- Telegram и заблокированные ресурсы через выбранный прокси;
- encrypted DNS и маршрутизация DIRECT/PROXY;
- переходы Wi-Fi → LTE и восстановление Activity/процесса;
- Quick Settings tile, foreground-уведомление и ручное переподключение;
- Kill Switch без прямой утечки трафика;
- системные Always-on VPN + lockdown и автоматический старт после reboot.
