# SLAVE VPN v0.2.41-dev.20

Служебная Dev-сборка: приватность и чистка. Протоколы и ядро без изменений
(dev.18/dev.19).

## Что изменилось

### Приватность

- Определение страны узлов по IP теперь отключается в настройках. По
  умолчанию включено (как раньше); при выключении IP-адреса серверов
  подписки больше не отправляются внешнему сервису геолокации ipwho.is —
  страна определяется по имени узла.
- Просмотр журнала диагностики редактирует все поля записи (ранее
  необработанными могли остаться поля ошибок и URL).
- DNS-резолвы российских доменов в режиме обхода шифруются (Yandex DoH,
  прямой перенос) вместо открытого UDP.

### Удалено

- Экспериментальный режим совместимости REALITY для отдельного узла:
  полевые испытания подтвердили, что на отказ узла он не влияет.

### Исправлено

- Кнопки «Проверить/Подключить» на приветственном экране переносятся на
  новую строку в узком окне вместо обрезания.
- Скрытие баннера обновления действует 7 дней, а не бессрочно; версия
  больше не теряется из вида навсегда.

### Внутреннее

- Тесты парсера ссылок расширены (ss/vmess/trojan; 25→33 в config-пакете).
