# SLAVE VPN v0.2.41-dev.17

Проверочная Dev-сборка для Windows и Android с дополнительной совместимостью
современных VLESS REALITY-ключей на мобильных сетях.

## Что исправлено

- Для ключей с `pqv` увеличенный гибридный ClientHello делится на небольшие
  корректные TLS-записи, чтобы операторские фильтры не отбрасывали его по пути.
- Фрагментация применяется только к первому ClientHello и только для таких
  ключей; обычные узлы используют прежний сетевой путь.
- Сохраняются исправления dev.16: современная версия REALITY-клиента,
  ML-DSA-65-проверка, X25519/ML-KEM и отпечаток `chrome`.
- Одинаковое исправленное ядро подготовлено для Windows и Android.

## Файлы

- `SlaveAppsVPN-Android.apk`
- `SlaveAppsVPN-Setup-v0.2.41-dev.17.exe`
- `SlaveAppsVPN-Portable-v0.2.41-dev.17.exe`
- `latest.yml`, blockmap и `SHA256SUMS.txt`

## Что проверить владельцу ключа

1. Обновиться до `dev.17` на Android или Windows и обновить подписку.
2. Выбрать узел Orel и дождаться результата проверки задержки.
3. Открыть несколько сайтов через VPN и проверить отсутствие
   `context deadline exceeded` для выбранного узла.
4. Повторить тест на мобильной сети и Wi-Fi, затем после переподключения.

Ключи и адреса подписок в исходный код, тесты и заметки выпуска не включались.
