# SLAVE VPN v0.2.41-dev.13

Development-channel regression candidate for Windows and Android.

## User-visible fixes

- Android subscriptions survive application restarts even when Capacitor
  Preferences is briefly unavailable during startup.
- A valid native mirror repairs a corrupt local subscription index.
- The last successfully parsed node list stays available during temporary
  subscription, TLS, DNS, or parser failures.
- Equivalent sources are collapsed deterministically, preventing duplicated
  server rows while respecting subscription priority.
- The first connection-quality check shows progress while VPN and DNS settle,
  and retries before reporting that internet access is unavailable.
- Windows lifecycle, recovery, saved-node fallback, IPC diagnostics, and TUN
  restart behavior include the regression fixes prepared after dev.12.
- Manual GitHub Android publication builds the immutable requested tag and
  derives the application version from that tag, preventing a branch/tag APK
  mismatch.
- Development builds display release notes only for their exact published
  version, avoiding stale notes from another prerelease.

## Release status

This file describes the prepared candidate. GitHub Actions must still build and
sign the Android production APK, verify its pinned certificate, attach the
artifacts to the prerelease, and pass online download/feed verification before
the release is considered published.
