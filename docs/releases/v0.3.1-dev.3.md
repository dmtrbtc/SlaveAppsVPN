# SLAVE VPN v0.3.1-dev.3

Предварительная версия для канала Dev. Основные улучшения относятся к Android.

- Повышена стабильность подключения при переключении между Wi-Fi и мобильной сетью.
- Улучшено автоматическое восстановление соединения и отключение VPN пользователем.
- Повышена надёжность загрузки и обработки подписок.

Тестирование стабильности в разных сетях продолжается.
