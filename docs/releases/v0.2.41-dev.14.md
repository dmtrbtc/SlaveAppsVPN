# SLAVE VPN v0.2.41-dev.14

Проверочная Dev-сборка для Windows и Android перед выпуском `v0.2.41` в
стабильный канал.

## Что исправлено

- Если выбранный вручную сервер исчез из подписки, приложение переключается на
  автоматический выбор вместо повторяющейся ошибки `proxy not exist`.
- Поддержан импорт экранированных VLESS Reality-ссылок из мессенджеров и
  Markdown. Такая ссылка сохраняется как одиночный прокси, а не ошибочно
  загружается как веб-подписка.
- Параметр Reality `spx` сохраняется; наличие `pqv` включает поддерживаемый
  Mihomo режим гибридного X25519/ML-KEM обмена.
- Усилены проверки сборки и публикации: артефакты создаются из точного тега,
  Android release требует production-подпись, а зависимости устанавливаются по
  зафиксированному lock-файлу.
- Репозиторный lint теперь действительно анализирует TypeScript/JavaScript и
  останавливает сборку при предупреждениях.

## Что проверить

1. Добавление обеих подписок/одиночных VLESS-ссылок и переключение между ними.
2. Подключение, смену режима и повторное подключение после обновления подписки.
3. Windows: установка поверх `dev.13`, сон/пробуждение и смена сети.
4. Android: установка поверх предыдущей сборки без потери подписок и настроек.

## Ограничение Reality

Mihomo использует гибридный X25519/ML-KEM handshake, но пока не проверяет
ML-DSA-65 значение из `pqv`. Полная Xray-семантика потребует отдельного
Xray-движка или новой поддержки в Mihomo.
