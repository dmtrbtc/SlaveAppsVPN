# SLAVE VPN v0.3.0

Стабильный релиз: вся линейка 0.2.41-dev (dev.1–dev.21) плюс предрелизная
стабилизация. Рекомендуется всем пользователям v0.2.40 и Dev-канала.

## Главное с прошлого стабильного релиза (v0.2.40)

### Надёжность и восстановление

- Стабилизирован жизненный цикл движка: серийные обновления конфигурации,
  защита от гонок при переключении узлов, откат последнего рабочего профиля.
- Падение приложения трижды за короткое время автоматически включает
  безопасный режим (без движка и провайдера) вместо цикла перезапусков.
- Неудачное применение обновлённых подписок к активному туннелю видно
  в журнале диагностики — туннель больше не молча работает со старыми узлами.

### Обновления

- Dev-сборки всегда получают обновления из Dev-канала (ранее установленный
  dev-клиент на канале «Стабильная» не видел обновлений вообще).
- Android не предлагает установку из релизов без APK (Windows-only теги).
- Скрытие баннера обновления действует 7 дней, а не бессрочно.

### Приватность

- Российские домены в режиме обхода резолвятся шифрованным Yandex DoH
  напрямую вместо открытого UDP.
- Локальные/корпоративные имена (geosite:private) не уходят в системный
  резолвер под туннелем (фикс петли DNS).
- Определение страны узлов по IP отключается в настройках (IP-адреса
  серверов подписки не отправляются внешнему сервису).
- Журнал диагностики редактирует все поля записи перед показом.

### Современный REALITY

- Поддержка пост-квантовых рукопожатий X25519/ML-KEM, проверки ML-DSA-65
  (pqv), фрагментации увеличенного ClientHello и версии клиента 26.9.9 —
  единый набор патчей ядра mihomo v1.19.30 на Windows и Android.

### Интерфейс

- Индикация нестабильных узлов: карантин — «Офлайн», серия провалов —
  «Нестабильный», предупреждение в селекторе подключения.
- Балансировщик узлов работает: настоящий секрет API и актуальный список
  узлов из подписки (ранее пробы всегда отклонялись).
- Кнопки переносятся/обрезаются корректно в узких окнах; устаревший пинг
  не «оживает» после неудачного замера.
- SoundCloud работает в режиме «Заблокировано» (сервис сам закрывает
  доступ с российских IP).

### Инфраструктура (для сборок из исходников)

- Релизные артефакты собираются только после полного прогона тестов;
  mihomo -t на каждый PR; пины SHA256 для всех бинарников ядра;
- Тестовое покрытие выросло на ~110 тестов (парсеры ссылок, DNS-компилятор,
  балансировщик, probing, API-клиент, state-sync, Kotlin).

## Известные ограничения

- Установщик Windows не подписан (SmartScreen покажет предупреждение при
  первой установке — «Подробнее → Выполнить в любом случае»). Осознанное
  решение: без платного сертификата; репутация накопится со временем.
