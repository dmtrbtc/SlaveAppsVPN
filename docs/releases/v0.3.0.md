# SLAVE VPN v0.3.0

Стабильный выпуск, объединяющий всю линейку тестовых сборок 0.2.41 и финальную стабилизацию. Рекомендуется всем пользователям v0.2.40 и любой Dev-сборки. Обновление ставится поверх — настройки, подписки и выбранный сервер сохраняются.

## Единое ядро и подписки

- Одна версия ядра Mihomo на Windows и Android, включая ARM64.
- Починено автообновление на Android — загрузка больше не «висит на нуле».
- Гибкая маршрутизация под ваши сервисы и единый конвейер маршрутизации в общем ядре; корректные версии в ленте обновлений; стабильная работа подписок на обеих платформах.
- Настройки Windows и Android используют один механизм хранения — поведение приложений теперь одинаково.

## Подключение держится

- Движок уверенно переживает частую смену настроек и узлов: конфликтующие команды не ломают туннель, при неудаче автоматически возвращается последний рабочий профиль.
- Подписки переживают перезапуск даже при недоступном хранилище, повреждённый индекс чинится сам, одинаковые источники не дублируются.
- Переключение узлов закрывает старые соединения только после успешного нового; если выбранный сервер пропал — приложение само возвращается к живому.
- При серии падений включается безопасный режим вместо бесконечных перезапусков.
- Неудачное применение обновлённых подписок видно в журнале диагностики — туннель не работает молча со старыми узлами.

## Современный REALITY

- Поддержка пост-квантовых расширений Xray: шифрование X25519/ML-KEM, проверка ML-DSA-65 и фрагментация ClientHello для мобильных сетей. Ключи с параметром `pqv` подключаются без дополнительных настроек, набор патчей ядра одинаков на обеих платформах.
- Импорт ссылок из чатов работает даже с «сломанным» экранированием; параметры spx и pqv сохраняются корректно.

## Обновления больше не застревают

- Клиенты Dev-сборок всегда получают предложения обновлений — раньше установленная dev-версия могла не видеть новых релизов вообще.
- Android не предлагает установку из релизов без Android-версии; скрытый баннер напомнит о себе через неделю, а не исчезнет навсегда.

## Приватность

- DNS-запросы российских доменов в режиме обхода шифруются вместо открытого текста.
- Определение страны узлов по IP отключается в настройках — адреса ваших серверов не уходят внешнему сервису.
- Журнал диагностики скрывает чувствительные данные во всех полях перед показом и копированием.
- Починена петля DNS для локальных и корпоративных имён под туннелем Android.

## Узлы под контролем

- Балансировщик заработал по-настоящему: корректный доступ к API ядра и живой список узлов из подписки; о задержке каждого узла судит только свежая проба.
- Нестабильные узлы видны сразу: метки «Нестабильный» и «Офлайн» в списке серверов, предупреждение при выборе проблемного узла.

## Мелочи, которые злили

- SoundCloud работает в режиме «Заблокировано».
- Кнопки не обрезаются в узких окнах; «пинг» мёртвого узла не выдаёт себя за свежий.

## Обновление

Установите поверх текущей версии — всё сохранится. Android: установите APK поверх, данные останутся на месте.

## Известная особенность

При первой установке на Windows SmartScreen может показать предупреждение — нажмите «Подробнее → Выполнить в любом случае». Контрольные суммы всех файлов — в `SHA256SUMS.txt` рядом с загрузками.

## Файлы

- Windows (установщик): `SlaveAppsVPN-Setup-v0.3.0.exe`
- Windows (портативный): `SlaveAppsVPN-Portable-v0.3.0.exe`
- Android: `SlaveAppsVPN-Android.apk`
