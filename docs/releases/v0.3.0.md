# Slave VPN v0.3.0

Стабильный выпуск для Windows и Android, объединяющий изменения серии 0.2.41-dev и этапа стабилизации.

## Подключение и подписки

- Windows и Android используют согласованный набор патчей mihomo v1.19.30.
- Общая логика маршрутизации и настроек дополняется платформенными адаптерами.
- Команды подключения и изменения профиля обрабатываются последовательно; при ошибке применения предусмотрен возврат к последнему рабочему профилю.
- Улучшены восстановление подписок, обработка повреждённого индекса и устранение дубликатов.
- Старые соединения закрываются после успешного переключения узла; при исчезновении сохранённого Android-узла выбирается SLAVE-AUTO.
- При цикле падений включается режим восстановления. Ошибки применения подписки доступны в журнале диагностики.

## Совместимость

- Обновлена совместимость REALITY: версия клиента 26.9.9, гибридный X25519/ML-KEM, проверка ML-DSA-65 (`pqv`) и фрагментация ClientHello для соответствующих конфигураций.
- Исправлена обработка экранированных ссылок; параметры `spx` и `pqv` сохраняются при импорте.
- Совместимость конкретного узла зависит от конфигурации сервера и условий сети.

## Обновления

- Dev-сборки проверяют Dev-канал, включая случаи, когда ранее был сохранён стабильный канал.
- Android проверяет наличие APK перед предложением обновления; предусмотрена резервная загрузка при проблеме системного загрузчика.
- Скрытие баннера обновления действует семь дней.

## DNS и данные

- Для российских доменов в соответствующих профилях используется прямой Yandex DoH вместо UDP; начальное разрешение имён имеет отдельные настройки.
- Исправлена DNS-петля для локальных и корпоративных имён на Android.
- В настройках можно отключить отправку IP узлов сервису определения страны `ipwho.is`.
- Обработка чувствительных данных в журнале распространена на строковые поля перед показом и копированием. Перед отправкой журнала проверяйте его вручную.

## Интерфейс и диагностика

- Балансировщик использует актуальный список подписок и аутентифицированные запросы к API ядра.
- После неудачного замера больше не показывается старое значение как свежая задержка.
- Добавлены индикаторы состояния узлов и предупреждение при выборе проблемного сервера.
- Исправлено размещение кнопок в узких окнах.
- Уточнены доменные правила SoundCloud и его медиа-CDN в выборочном профиле маршрутизации.

## Установка и обновление

- Windows Setup: `SlaveAppsVPN-Setup-v0.3.0.exe`.
- Windows Portable: `SlaveAppsVPN-Portable-v0.3.0.exe`.
- Android: `SlaveAppsVPN-Android.apk`.
- Контрольные суммы: `SHA256SUMS.txt` в файлах этого выпуска.

Обновление предназначено для установки поверх совместимой версии с сохранением настроек. Для Android требуется совместимая подпись и номер версии; старые тестовые APK могли быть подписаны иначе. При конфликте установки сначала уточните причину, не удаляйте данные приложения наугад.

Установщик Windows не имеет подписи издателя; SmartScreen может показать предупреждение. Перед запуском проверьте источник и SHA-256. Контрольная сумма не заменяет подпись издателя.
