# SLAVE VPN v0.3.0

Крупное обновление стабильного канала: вся линейка тестовых сборок 0.2.41
доведена до стабильного состояния. Рекомендуется всем — от v0.2.40 и с
любой Dev-сборки.

## Что стало лучше

### Подключение держится

- Движок переживает частую смену настроек и узлов без сбоев: конфликтующие
  команды больше не ломают туннель, при неудаче автоматически возвращается
  последний рабочий профиль.
- Если приложение падает несколько раз подряд, оно само переходит в
  безопасный режим вместо бесконечного цикла перезапусков.
- Нестабильные узлы видны сразу: рядом с узлом появляется «Нестабильный»
  или «Офлайн», а выборщик подключения предупреждает, прежде чем вы
  переключитесь на проблемный сервер.

### Обновления больше не застревают

- Клиенты тестовых (Dev) сборок теперь всегда получают предложения
  обновлений — раньше установленная dev-версия на стандартном канале могла
  не видеть новых релизов вообще.
- Android не предлагает установку из релизов, где нет Android-версии.
- Скрытый баннер обновления напомнит о себе через неделю, а не пропадёт
  навсегда.

### Приватность

- Запросы российских доменов в режиме обхода шифруются (ранее — открытым
  текстом, видным провайдеру).
- Кнопка в настройках отключает определение страны узлов по IP — адреса
  ваших серверов не уходят внешнему сервису.
- Журнал диагностики скрывает чувствительные данные во всех полях перед
  показом и копированием.

### Современные серверы REALITY

- Поддержка новейших handshake-расширений Xray (пост-квантовое шифрование
  X25519/ML-KEM, проверка ML-DSA-65, фрагментация ClientHello) — одинаково
  на Windows и Android. Ключи с параметром `pqv` подключаются без
  дополнительных настроек.

### Мелочи, которые злили

- SoundCloud наконец работает в режиме «Заблокировано» (сервис сам закрыл
  доступ с российских адресов — теперь он идёт через туннель).
- Кнопки интерфейса не обрезаются в узких окнах; старый «пинг» мёртвого
  узла не выдаёт себя за свежий.

## Обновление

Установите поверх текущей версии — настройки, подписки и выбранный сервер
сохраняются. Android: установите APK поверх, данные останутся на месте.

## Известная особенность

Установщик Windows не имеет цифровой подписи, поэтому при первой установке
SmartScreen покажет предупреждение. Нажмите «Подробнее → Выполнить в любом
случае» — это ожидаемо и безопасно: сборка публикуется из открытого
конвейера с контрольными суммами (файл SHA256SUMS.txt рядом с загрузками).

## Файлы

- Windows (установщик): `SlaveAppsVPN-Setup-v0.3.0.exe`
- Windows (портативный): `SlaveAppsVPN-Portable-v0.3.0.exe`
- Android: `SlaveAppsVPN-Android.apk`
- Контрольные суммы: `SHA256SUMS.txt`
