# SLAVE VPN v0.2.41-dev.19

Служебная Dev-сборка: закрытие итогов аудита 2026-09-24 — обновитель,
балансировщик, безопасный режим и наблюдаемость ошибок. Протоколы и ядро
без изменений (dev.18).

## Что исправлено

### Обновления

- Dev-сборки теперь всегда ищут обновления в Dev-канале. Ранее установленный
  `-dev.N` клиент с каналом по умолчанию «Стабильная» не мог увидеть ни одно
  обновление — именно так установки застревали на dev.17 при опубликованном
  dev.18. В настройках на Dev-сборках появилось пояснение.
- Android больше не предлагает APK из релизов без Android-ассета
  (Windows-only теги): перед показом баннера загрузка проверяется, а не
  отдаёт 404 при нажатии.

### Балансировщик узлов

- Пробы балансировщика аутентифицируются настоящим секретом API ядра
  (ранее все пробы отклонялись с 401, балансировщик фактически не работал).
- Список узлов для балансировки заполняется из актуального агрегата подписок
  при каждом включении (ранее был всегда пуст).

### Надёжность

- Автодетект цикла падений (3 запуска за 45 секунд) теперь действительно
  переводит приложение в безопасный режим, а не только пишет в журнал.
- Неудачное применение обновлённых подписок к активному подключению видно
  в журнале диагностики (событие «subscriptions.reload_failed») — раньше
  туннель молча продолжал работать со старым списком узлов.
- Неудачный замер задержки узла больше не «оживляет» устаревшее значение
  пинга.

### Прочее

- Диагностический режим совместимости REALITY для выбранного узла (в
  списке серверов, только при отключённом VPN): временно отключает
  post-quantum расширения хендшейка для проблемных серверов. Обычная
  защита легко восстанавливается.
- Харденинг внутренних вызовов ОС (без изменения поведения).
