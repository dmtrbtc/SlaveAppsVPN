# SLAVE VPN v0.2.41-dev.8

Dev-сборка с исправлением определения тега обновления в GitHub Atom feed.

## Что исправлено

- updater больше не принимает редактируемый заголовок GitHub Release за тег;
- канонический тег извлекается из ссылки `/releases/tag/...`;
- заголовок используется только как совместимый резервный вариант;
- percent-encoded теги безопасно декодируются;
- Android renderer и Windows main используют один общий Atom-парсер;
- пользовательский заголовок вида `SLAVE VPN v0.2.41-dev.8` больше не создаёт
  несуществующий download URL и HTTP 404.

## Проверено

- регрессионные updater tests: 2/2;
- полный Windows renderer suite: 18/18;
- Windows typecheck, lint и production build;
- architecture boundaries: 295/295;
- реальный сценарий обновления Android `v0.2.41-dev.5` → `v0.2.41-dev.7`
  после восстановления канонического release title.
