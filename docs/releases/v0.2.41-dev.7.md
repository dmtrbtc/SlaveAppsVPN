# SLAVE VPN v0.2.41-dev.7

Dev-сборка с единым Core-конвейером маршрутизации и компиляции Android-конфига.

## Что изменено

- режимы VPN на Android используют общий `routingPolicy` из `@slave-vpn/core`;
- Android-специфичные anti-loop, geo/rule-provider и sniffer-настройки сохранены
  в platform extras без второго дерева маршрутизации;
- сбор platform data и компиляция Mihomo YAML теперь проходят через типизированный
  `CoreConfigProvider`;
- удалён дублирующий Android wrapper `compile-config.ts`;
- Core централизованно журналирует размер скомпилированного конфига и безопасные
  предупреждения, не записывая сам YAML и данные подписки;
- порядок recovery → загрузка настроек и прокси → компиляция → запуск Mihomo
  сохранён.

## Проверено

- Core tests: 48/48;
- Config tests: 38/38;
- Windows renderer regressions: 16/16;
- architecture boundaries: 295/295;
- typecheck, lint, Mihomo config validation и Windows build;
- Android `cap sync`, lint и сборка APK;
- физическое устройство Android 16: установка поверх dev-пакета с сохранением
  данных, disconnect/connect, `mode=bypass`, `Slave-EE`, Mihomo v1.19.30;
- Google traffic через `SLAVE-SELECT[Slave-EE]`, российский Yandex traffic через
  `DIRECT`, foreground VPN service без crash/fatal/ANR.
