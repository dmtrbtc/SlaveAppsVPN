# SLAVE VPN v0.3.1-dev.2

Предварительная версия для канала Dev на Android и Windows.

- Обновлена совместимость VLESS REALITY с Xray 26.11.9. Добавлен выбор TLS fingerprint для поддерживаемых профилей.
- Android обнаруживает NAT64 в мобильной сети. Slave-NL2 проверен по LTE МегаФона в классическом режиме REALITY.
- Telegram использует выбранный VPN-узел. Скорость исходящего трафика зависит от мобильной сети и маршрута.
- NL-Backup с TCP FinalMask проверен через встроенный Xray на Android по Wi-Fi и LTE. На Windows тот же профиль передал данные через локальный прокси клиента. Проверка Windows TUN остаётся открытой.
- Импорт сохраняет параметры WebSocket и XHTTP, а также отдельно названные профили на одном сервере.
