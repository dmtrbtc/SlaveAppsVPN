# SLAVE VPN v0.3.1-dev.1

Dev-сборка: экономия батареи Android и защита от повреждённых REALITY-ключей.

## Что исправлено

### Батарея Android

- при подключённой VPN приложение больше не крутит фоновые опросы круглосуточно:
  когда оно свёрнуто или экран выключен, все периодические запросы (статус,
  трафик, соединения, проверки связи) останавливаются и мгновенно
  возобновляются при возврате в приложение;
- уведомление с текущей скоростью больше не пересобирается каждые 2 секунды
  всю ночь: живая скорость обновляется только при включённом экране, а иконка
  уведомления создаётся один раз, а не при каждом обновлении;
- ядро на Android шлёт TCP keep-alive раз в 30 секунд вместо 15 — модем реже
  просыпается в простое; уровень логов ядра понижен с info до warning
  (меньше лишней работы при каждом соединении);
- частота автопроверок узлов не менялась: скорость переподключения Телеграма
  остаётся прежней.

### Повреждённые REALITY-ключи

- подписка или ссылка с повреждённым ключом проверки pqv больше не ломает
  загрузку всего конфига: узел продолжает работать в классическом режиме
  REALITY, приложение предупреждает о проблеме и предлагает запросить новую
  ссылку;
- то же предупреждение появляется при вставке такой ссылки из буфера обмена;
- события карантина узлов различают «сервер молчит» и ошибку протокола.

## Что изменено

- загрузчик бинарников ядра больше не перезаписывает локально пересобранный
  mihomo стоковой версией без явного запроса.

## Проверено

- полный unit-suite: config 52/52, core 83/83;
- typecheck всех пакетов монорепо;
- production-сборка renderer (общая для Windows и Android).

APK из этой сборки — предмет ручного QA на устройстве: ночь с подключённой
VPN, замер расхода батареи, поведение уведомления при выключенном экране и
скорость реакции после разблокировки.
