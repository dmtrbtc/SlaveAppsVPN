# SLAVE VPN v0.2.41-dev.15

Проверочная Dev-сборка для Windows и Android с исправлениями переключения
серверов и совместимости новых VLESS REALITY-подписок.

## Что исправлено

- При выборе другого сервера старые активные соединения закрываются только
  после успешного переключения. Приложения сразу переподключаются через новый
  узел, а не продолжают использовать прежний.
- Ошибка выбора больше не сохраняет несуществующий или отклонённый сервер.
  Android и Windows восстанавливают предыдущий рабочий выбор.
- Если сохранённый Android-узел исчез из обновлённой подписки, перед запуском
  ядра выбирается `SLAVE-AUTO`.
- Для новых REALITY-серверов с X25519/ML-KEM принудительно используется
  совместимый отпечаток `chrome`; исправлены проверки публичного ключа и
  короткого идентификатора.
- Диагностика различает ошибки подписки, REALITY, TLS, DNS, авторизации,
  недоступной сети, сброса соединения, тайм-аута и TUN, не показывая ключи и
  адреса из сырых логов.
- Выбор ноды стал однозначным: отдельно показаны «Выбран» и «Активен», ручной
  выбор автоматически отключает балансировщик, сервер можно выбрать до
  подключения, а автовыбор включается одной заметной кнопкой.
- Незавершённый пункт Xray убран из настроек. Старое сохранённое значение Xray
  автоматически возвращается на рабочий Mihomo.

## Что проверить

1. Установить сборку поверх `dev.14`, сохранив подписки и настройки.
2. Подключиться через заведомо рабочий узел, открыть несколько сайтов и затем
   выбрать другой узел: старые соединения должны исчезнуть.
3. Проверить переподключение, смену режима, сон/пробуждение и смену сети.
4. Проверить недоступный сервер: интерфейс не должен сохранять ложный выбор, а
   в диагностике должна появиться понятная категория ошибки.

## Ограничение REALITY

Mihomo поддерживает необходимый гибридный X25519/ML-KEM handshake с отпечатком
`chrome`, но не выполняет полную ML-DSA-65 проверку значения `pqv`. Сервер также
должен быть доступен по TCP из сети устройства.
