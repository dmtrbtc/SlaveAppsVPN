# Руководство пользователя Slave VPN

Руководство для стабильной версии **v0.3.0**, Windows и Android. Названия элементов приведены по текущему интерфейсу; в старых версиях они могут отличаться.

[Загрузки](https://github.com/dmtrbtc/SlaveAppsVPN/releases/latest) · [Поддержка](../SUPPORT.md) · [Обработка данных](DATA_HANDLING.md)

## Установка

### Windows

Клиент выпускается для 64-разрядной Windows. Для обычной установки используйте Setup, для запуска без установщика — Portable. Обе версии требуют повышения прав для TUN-адаптера. Рабочее окружение — Windows 10/11 x64; другие системы и Windows ARM64 отдельно не подтверждены.

1. Откройте страницу стабильного релиза и скачайте подходящий `.exe` вместе с `SHA256SUMS.txt`, если он опубликован.
2. Сравните SHA-256 скачанного файла с записью в файле контрольных сумм, например через `Get-FileHash -Algorithm SHA256` в PowerShell.
3. Запустите установщик либо Portable и подтвердите системный запрос прав, если доверяете источнику файла.
4. Откройте приложение и добавьте конфигурацию.

В v0.3.0 отсутствует подпись издателя Windows. SmartScreen может показать предупреждение. Контрольная сумма помогает обнаружить повреждение загрузки, но не заменяет подпись издателя; при несовпадении суммы файл не запускайте.

### Android

Требуются Android 7.0 (API 24) или новее, актуальный Android System WebView и процессор ARM64 или ARMv7. Минимальная версия из настроек сборки не означает проверку каждой прошивки. Для x86 APK не предоставляется.

1. Скачайте `SlaveAppsVPN-Android.apk` со страницы релиза.
2. Разрешите установку приложений для того источника, через который открываете APK.
3. Установите приложение. При первом подключении подтвердите системный запрос на создание VPN.
4. При запросе разрешите уведомления, чтобы видеть состояние фонового сервиса.

## Добавление конфигурации

| Способ на первом экране | Что требуется |
|---|---|
| Аккаунт | Доступ к личному кабинету совместимого оператора |
| Подписка-URL | Ссылка на подписку, предоставленная оператором |
| Одиночная ссылка | Совместимая конфигурация сервера, например `vless://…` |

Ссылка на подписку и ключ сервера могут предоставлять доступ к вашей услуге. Не размещайте их в Issues, скриншотах или публичных сообщениях.

В разделе «Подписки» можно добавить несколько источников, обновить их, изменить порядок и удалить ненужные. При совпадении узлов учитывается приоритет источника. Ошибка обновления не обязательно означает, что подписка истекла: проверьте сеть и ответ оператора.

## Аккаунт

Вход по email или Telegram, сведения о подписке, баланс, устройства, продление и автопродление доступны только при поддержке подключённого кабинета. Некоторые действия открывают сайт оператора или Telegram.

Условия оплаты, возврата, лимиты устройств и обработку данных аккаунта определяет оператор. Установка клиента сама по себе не создаёт подписку и не предоставляет серверы.

## Подключение и выбор узла

1. Обновите подписку и дождитесь появления списка серверов.
2. Выберите узел вручную или автоматический режим.
3. Нажмите кнопку подключения и дождитесь результата.
4. При ошибке откройте «Диагностику» и запишите сообщение вместе с версией приложения.

Задержка отражает конкретную проверку узла. Отсутствие результата обозначается `—`; удачный замер не гарантирует скорость или доступность всех ресурсов. Статистика показывает наблюдаемую активность подключения.

## Маршрутизация

Раздел «Маршрутизация» определяет, какие соединения направляются через туннель, напрямую или отклоняются. Ни один режим не обеспечивает абсолютную анонимность.

Ниже приведены **существующие названия интерфейса**, чтобы было проще найти настройку:

| Название в приложении | Поведение |
|---|---|
| «Только заблокированное» | Выборочная маршрутизация по встроенным спискам и правилам; основной маршрут — прямой |
| «Обход» | Российские назначения по правилам — напрямую; основной маршрут — через туннель |
| «Полный VPN» | Основной маршрут — через туннель |
| «Раздельный туннель» | Выбор по приложениям или процессам с учётом платформы |
| «Свой» | Настройка сценариев и собственных правил |

Результат зависит от собственных правил, системных исключений, доступности списков и платформенных настроек. Основной маршрут не означает, что абсолютно каждый пакет устройства следует ему.

### Свои правила

Для домена можно выбрать «Через VPN», «Напрямую» или «Блокировать». Правило с поддоменами охватывает также дочерние имена. Проверяйте результат в списке активных соединений. Не добавляйте неизвестные удалённые списки: их содержимое влияет на направление трафика.

### Приложения и процессы

На Android раздел «Приложения и VPN» управляет включением приложений в VPN-сервис:

- «Все» — фильтрация приложений отключена; затем действуют правила маршрутизации.
- «Только выбранные» — в VPN-сервис включаются отмеченные приложения.
- «Кроме выбранных» — отмеченные приложения исключаются из VPN-сервиса.

Изменение фильтра может потребовать переподключения. Готовый список банковских приложений служит для их исключения из туннеля; он не гарантирует успешный вход в банк.

На Windows выбор процессов применяется через правила сетевого ядра. Это отличается от системного фильтра Android: проверьте совпадение имени процесса и итоговый маршрут. Если выбран раздельный режим, но список пуст, прочитайте предупреждение в интерфейсе перед подключением.

## DNS

В разделе «DNS» выбираются профиль, стратегия и DoH-провайдер. В v0.3.0 доступны Cloudflare, Google, Quad9 и собственный адрес. DoH шифрует запросы между клиентом и соответствующим резолвером; это не обещание отсутствия любых DNS-запросов вне туннеля.

Для запуска соединения, разрешения имён узлов, локальных и корпоративных имён могут применяться отдельные резолверы и прямые маршруты. Проверяйте совместимость своих настроек с рабочей сетью. Подробности — в [справке об обработке данных](DATA_HANDLING.md).

## Работа в фоне

На Android доступны уведомление VPN-сервиса, плитка быстрых настроек и параметры автоподключения. Ограничения батареи в прошивке могут прервать фоновую работу; настройку исключения используйте при необходимости.

Kill Switch и системные Always-on VPN / блокировка соединений без VPN — разные механизмы. Их поведение зависит от настроек Android и исключённых приложений. В v0.3.0 отдельный переключатель Kill Switch для Windows скрыт; не рассчитывайте на системную блокировку прямого трафика средствами клиента Windows.

## Обновление

В настройках доступны стабильный канал и Dev. Стабильный канал предлагает финальные выпуски; установленная Dev-сборка проверяет предварительные версии по правилам своего канала.

- **Windows:** встроенный обновитель установочной версии загружает пакет и предлагает перезапуск. Portable можно заменить файлом из нужного релиза после закрытия приложения.
- **Android:** приложение загружает APK, затем открывает системное подтверждение установки. При проблеме системного загрузчика предусмотрена резервная загрузка.

Обновление Android поверх существующей установки требует совместимой подписи и подходящего номера версии. Если система сообщает о конфликте, не удаляйте приложение наугад: сначала сохраните необходимые сведения о конфигурации и обратитесь в поддержку. Старые тестовые APK могли иметь другую подпись.

## Диагностика и частые вопросы

### Узлы не появились

Обновите подписку, проверьте её срок и доступность источника. При нескольких источниках проверьте, что нужный включён. Вопросы содержимого подписки адресуйте оператору.

### Подключение есть, но нужный ресурс недоступен

Проверьте результат свежего замера узла, сработавшее правило, настройки DNS и доступность самого ресурса. Успешное состояние VPN не доказывает работоспособность каждого маршрута. Для сравнения используйте другой разрешённый вам узел.

### Windows не подключается

Проверьте подтверждение запроса администратора, наличие компонентов из официального дистрибутива и сообщения диагностики. Не отключайте защиту ОС целиком ради запуска клиента.

### Android не начинает загрузку обновления

Подождите перехода на резервную загрузку. Если старая версия её не поддерживает или ошибка повторяется, скачайте APK вручную со страницы нужного релиза и проверьте совместимость установки.

### Android останавливает соединение в фоне

Проверьте разрешения фонового сервиса, настройки батареи и системные параметры VPN. Поведение зависит от производителя устройства.

### Как сообщить об ошибке

Укажите ОС, версию клиента, шаги, ожидаемый и фактический результат. В журнале найдите события вокруг момента ошибки. Автоматическое скрытие чувствительных данных не заменяет ручную проверку: удалите адреса подписок, токены, ключи и персональные данные перед отправкой. [Правила обращения](../SUPPORT.md).
