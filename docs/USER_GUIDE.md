## 1. Установка

### 🪟 Windows
1. Скачайте **`SlaveAppsVPN-Setup-vX.Y.Z.exe`** со [страницы релизов](https://github.com/dmtrbtc/SlaveAppsVPN/releases/latest).
2. Запустите установщик. Нужны **права администратора** — приложение создаёт сетевой TUN-адаптер.
3. При первом запуске Windows SmartScreen может предупредить о неизвестном издателе → **«Подробнее» → «Выполнить в любом случае»** (сборка пока без коммерческой подписи).

> Есть и **портативная** версия (`-Portable-`) — без установки, но тоже запускается от администратора.

### 🤖 Android
1. Скачайте **`SlaveAppsVPN-Android.apk`**.
2. Разрешите **установку из неизвестных источников** (Android попросит сам).
3. При первом подключении система покажет запрос **«Разрешить VPN-подключение?»** → **OK**.

> Нужен телефон на **arm64** (любой современный). x86-эмуляторы не поддержаны.

## 2. Первый запуск

На экране приветствия — три способа добавить серверы. Первый рекомендуется.

| Способ | Когда выбирать |
|---|---|
| **🧑 Аккаунт SLAVE** | У вас есть аккаунт в личном кабинете (email или Telegram). Подписка подтянется **автоматически**. |
| **🔗 Подписка-URL** | У вас есть прямая ссылка на подписку (Clash/YAML, base64, sing-box). |
| **⚡ Одиночная ссылка** | У вас есть одна ссылка на сервер: `vless://…`, `vmess://…`, `trojan://…`. |

**Рекомендуется «Аккаунт SLAVE»** — вход по email (основной способ) или через Telegram, после чего подписка добавляется сама.

## 3. Личный кабинет

Раздел **«Аккаунт»** (в сайдбаре на десктопе; на мобиле — через карточку «Личный кабинет» на вкладке «Подписки»).

### Вход
- **Email** (основной): введите почту и пароль. Нет аккаунта — «Регистрация»; забыли пароль — «Забыли пароль?».
- **Telegram**: кнопка «Войти через Telegram» → откроется бот → нажмите **Start** и **«✅ Да, войти»**.

После входа подписка **импортируется автоматически** и появляется на вкладке «Подписки».

### Что внутри
- **Личность** — имя, email + статус подтверждения, статус Telegram.
- **🔗 Привязать Telegram** — если вошли по email, можно привязать Telegram-аккаунт (кнопка открывает веб-кабинет, где это делается). После привязки нажмите «Обновить».
- **💳 Баланс** — текущий баланс и история операций; кнопка «Пополнить баланс» открывает кабинет в браузере.
- **📅 Продление** — варианты продления с ценами + переключатель **автопродления**.
- **📱 Устройства** — список устройств на подписке, лимит, удаление лишних.

## 4. Подключение

На главном экране — большая круглая кнопка (**Aurora orb**):

- **Серая** — отключено. Нажмите, чтобы подключиться.
- **Оранжевая (пульсирует)** — подключение.
- **Зелёная** — защищено.
- **Красная** — ошибка (нажмите «Повторить»).

Справа — **выбор сервера**:
- **Авто** — приложение само выбирает быстрейший узел (по пингу).
- **Ручной** — выберите конкретный сервер из списка (рядом — пинг в мс).

Внизу — живая статистика: скорость, сессия, активные соединения, спарклайн трафика.

## 5. Режимы маршрутизации

Раздел **«Маршрутизация»**. Режим — это **главный переключатель**, он определяет, как идёт трафик. На дашборде виден индикатор **«куда идёт трафик»**.

| Режим | Что делает | Кому |
|---|---|---|
| **🛡️ Обход** *(рекомендуется для РФ)* | Российские сайты и банки — **напрямую**, заблокированное и всё остальное — **через VPN**. | Большинству пользователей в РФ. |
| **🌍 Полный VPN** | **Весь** трафик через VPN, включая российские сервисы. | Максимальная анонимность. |
| **✂️ Раздельный** | Через VPN идут **только выбранные приложения** (см. ниже). | Точечный контроль. |
| **⚙️ Свой** | Гибкая настройка **сценариями** (AI, стриминг, игры, RuNet Freedom…). | Продвинутым. |

> В режиме **«Обход»** российские банки и госуслуги остаются на российском IP — даже если их CDN за рубежом (есть курируемый список РФ-сервисов).

## 6. Раздельный туннель

Блок **«Приложения и VPN»** (на Android) — выбор, какие приложения идут через VPN, а какие мимо. Работает **в любом режиме**.

| Режим панели | Эффект |
|---|---|
| **Все** | Раздельного туннеля нет — весь трафик через VPN. |
| **Только выбранные** | Через VPN идут **только** отмеченные приложения, остальное — напрямую. |
| **Кроме выбранных** | Отмеченные идут **напрямую, мимо VPN**; остальное — через VPN. |

### 🏦 Банки и VPN
Многие банковские приложения (например ВТБ) **блокируют вход при любом активном VPN**. Решение — в один тап:

> **«Приложения и VPN» → «Банковские приложения — мимо VPN»**

Приложение само переключит на «Кроме выбранных» и отметит установленные банки. После — переподключитесь. Банк перестанет «видеть» VPN и вход заработает.

> ⚠️ Если выбрали режим **«Раздельный»**, но панель стоит на **«Все»** — весь трафик пойдёт через VPN (приложение об этом предупредит жёлтым баннером). Выберите «Только выбранные» и отметьте приложения.

## 7. Сценарии маршрутизации

Доступны в режиме **«Свой»**. Делятся на две группы:

- **База** *(выберите один профиль)* — задаёт поведение по умолчанию: RoscomVPN (РФ-обход), Smart Global (всё через VPN), Smart Russia.
- **Дополнения** *(комбинируйте любые)* — AI-сервисы, Стриминг, Игры (напрямую, низкий пинг), Ad Block, RuNet Freedom.

Списки доменов (RKN и др.) — в блоке **«Источники правил»**, с авто-обновлением.

## 8. DNS

Раздел **«DNS»**. По умолчанию настроено безопасно (DoH через туннель, без утечек). Можно выбрать DoH-провайдера (Cloudflare / Google / Quad9 / AdGuard / свой) и стратегию. Российские домены резолвятся через российские резолверы — без «утечки» и шума в логах.

## 9. Диагностика

Раздел **«Диагностика»**:
- **Системная информация** — версия движка, платформа.
- **Логи** — поток событий ядра в реальном времени; можно копировать/поделиться для отчёта об ошибке.
- **Проверка соединения** — внешний IP, страна, задержка.
- **Self-test** — набор автоматических проверок.

> Если что-то не работает — откройте **Логи**, поймайте момент проблемы и приложите к сообщению. По логам почти всегда видно причину.

## 10. Обновления

Приложение само проверяет новые версии (баннер сверху). Два канала в **Настройках → Обновления**:
- **Стабильный** — только финальные релизы.
- **Dev** — ранний доступ (`-dev`/`-rc` сборки).

На Android кнопка **«Обновить»** скачивает APK внутри приложения и затем открывает
системное подтверждение установки. Если системный загрузчик телефона не начинает
передачу, клиент автоматически переключается на резервную HTTPS-загрузку. На
Windows обновление также загружается внутри приложения и применяется после
перезапуска.

## 11. Частые вопросы

**В банк не пускает при включённом VPN.**
→ «Приложения и VPN» → «Банковские приложения — мимо VPN» → переподключитесь. См. [раздел 6](#6-раздельный-туннель).

**Российский сайт открывается с иностранным IP.**
→ Включите режим **«Обход»** — РФ-сервисы пойдут напрямую.

**На Windows не запускается / нет подключения.**
→ Запустите **от администратора** (нужно для TUN-адаптера).

**Тёмная тема.**
→ Настройки → Внешний вид → «Тёмная» (или «Системная»).

**Кнопка обновления ничего не делает (старые сборки Windows).**
→ Исправлено начиная с v0.2.8; обновитесь вручную один раз — дальше всё работает.

**Android показывает обновление, но загрузка остаётся на 0%.**
→ Это ошибка системного Download Manager, не самого APK. Исправлено в
`v0.2.41-dev.3`: после тайм-аута приложение автоматически использует резервную
HTTPS-загрузку. `v0.2.41-dev.2` и более ранние версии нужно один раз обновить вручную со
[страницы релиза](https://github.com/dmtrbtc/SlaveAppsVPN/releases/tag/v0.2.41-dev.3).

**Не подключается с первого раза.**
→ Иногда на холодном старте ядро/гео-базы ещё прогреваются — повторное подключение проходит. Если повторяется — пришлите лог из «Диагностики».
