## История и результаты проверок

[История изменений](../CHANGELOG.md) и [заметки выпусков](releases/) описывают соответствующие версии.

Файлы с именами `*_VERIFICATION`, `*_INVESTIGATION`, `*_READINESS`, `*_POSTMORTEM`, журналы этапов и планы рефакторинга — исторические инженерные материалы. Их даты, версии, команды и результаты сохраняются как свидетельства конкретной проверки. Они не подтверждают текущее состояние всех устройств и внешних сервисов и не заменяют руководство пользователя.

Технические идентификаторы режимов, имена функций и названия сторонних компонентов в таких материалах сохраняются для сопоставления с кодом.
