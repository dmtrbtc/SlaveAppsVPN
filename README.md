# Slave VPN

**Управляйте подключением с компьютера и смартфона.**

Приложение для Windows и Android с управлением подключениями, подписками, маршрутизацией и DNS. Добавьте конфигурацию своего оператора, выберите узел и настройте сетевое поведение под свои задачи.

[Скачать приложение](https://github.com/dmtrbtc/SlaveAppsVPN/releases/latest) · [Начать работу](docs/USER_GUIDE.md) · [Получить помощь](SUPPORT.md)

## Подключения в одном месте

- **Несколько источников.** Храните подписки и отдельные конфигурации в общем списке, обновляйте их и задавайте приоритет.
- **Понятный выбор узла.** Сравнивайте результаты проверки задержки, выбирайте сервер вручную или используйте автоматический выбор.
- **Управление маршрутами.** Задавайте правила для доменов, выбирайте профили DNS и разделяйте трафик приложений.
- **Диагностика под рукой.** Просматривайте состояние подключения, статистику и журналы при разборе неполадок.
- **Обновления из приложения.** Выбирайте стабильные выпуски или предварительные сборки для тестирования.

Клиенту нужна действующая подписка или совместимая конфигурация сервера. Доступность узлов, условия обслуживания и функции аккаунта определяет оператор.

## Возможности платформ

| Возможность | Windows | Android |
|---|---|---|
| Подписки и отдельные конфигурации | Да | Да |
| Ручной и автоматический выбор узла | Да | Да |
| Правила для доменов и профили DNS | Да | Да |
| Раздельная маршрутизация | По процессам | По установленным приложениям |
| Личный кабинет | При поддержке оператора | При поддержке оператора |
| Диагностика и статистика | Да | Да |
| Обновление | Установщик и встроенный обновитель | APK с системным подтверждением |
| Интеграция с системой | Трей, уведомления, автозапуск | VPN-сервис, уведомление, плитка быстрых настроек |

Поддерживаются VLESS / REALITY / XTLS-Vision, VMess, Trojan, Shadowsocks, Hysteria2 и TUIC в пределах возможностей встроенного ядра mihomo и импортируемой конфигурации. Совместимость конкретных параметров зависит от версии клиента и сервера.

Маршрутизация и DNS не обеспечивают абсолютную анонимность. Результат подключения зависит также от сети, ОС, конфигурации и доступности сервера. [Как обрабатываются данные](docs/DATA_HANDLING.md).

## Первый запуск

1. Скачайте подходящий файл и установите приложение либо запустите Portable.
2. Добавьте подписку или отдельную конфигурацию. Если оператор поддерживает личный кабинет, можно войти в аккаунт.
3. Выберите узел и нажмите кнопку подключения. Подтвердите системные разрешения.
4. Проверьте состояние соединения. При необходимости настройте маршрутизацию и DNS.
