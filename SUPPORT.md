# Поддержка Slave VPN

## Ошибка приложения или предложение

Откройте [обращение на GitHub](https://github.com/dmtrbtc/SlaveAppsVPN/issues/new/choose). Перед созданием проверьте существующие Issues и описание установленного релиза.

Для разбора ошибки нужны:

- платформа, версия ОС и версия Slave VPN;
- канал обновлений и тип установки: Setup, Portable или APK;
- шаги воспроизведения, ожидаемый и фактический результат;
- текст ошибки и небольшой проверенный фрагмент журнала, если он помогает воспроизведению.

Не публикуйте пароли, токены, ключи серверов, URL подписок, данные аккаунта и адреса частной инфраструктуры. На скриншотах закройте эти сведения. Не прикладывайте весь каталог данных приложения или готовую конфигурацию ядра.

## Подписка, оплата и серверы

Обращайтесь к оператору, который предоставил подписку. GitHub проекта предназначен для вопросов клиента; условия обслуживания, баланс, восстановление аккаунта и доступность узлов определяются оператором.

## Уязвимость

Используйте [приватное сообщение об уязвимости](https://github.com/dmtrbtc/SlaveAppsVPN/security/advisories/new). Не публикуйте детали в обычном Issue. Если приватная форма временно недоступна, создайте Issue только с просьбой предоставить приватный канал, без технических деталей и данных пострадавших.

[Политика безопасности](SECURITY.md)

## Сроки и версии

Фиксированное время ответа и устранения ошибки не обещается. Для первичной проверки используйте последний стабильный выпуск, если в обращении не исследуется конкретная регрессия. Dev-сборки предназначены для тестирования; состав функций проверяйте в заметках их версии.
